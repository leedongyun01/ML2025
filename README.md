# ML2025: Machine Learning & Data Analysis Study

2025년 머신러닝 및 데이터 분석 역량 강화를 위한 학습 저장소입니다. 파이썬의 핵심 라이브러리부터 데이터 전처리, 시각화, 그리고 실전 데이터셋 활용까지의 과정을 체계적으로 정리하고 있습니다.

## Repository Structure

본 저장소는 단계별 학습을 위해 다음과 같은 순서로 구성되어 있습니다.

### 1. 기초 라이브러리 (Foundations)
*   **NumPy (`1. Numpy.ipynb`)**: 수치 계산을 위한 다차원 배열(Array) 조작 및 벡터화 연산 기초
*   **Pandas (`2. Pandas1~3.ipynb`)**: Series와 DataFrame을 활용한 데이터 필터링, 그룹화, 병합 및 복잡한 데이터 조작
*   **Visualization**: 데이터의 인사이트를 도출하기 위한 시각화 도구 실습
    *   `3. Matplotlib.ipynb`: 파이썬 시각화의 기본이 되는 차트 생성
    *   `4. Seaborn.ipynb`: 통계 기반의 고수준 시각화 인터페이스
    *   `5. Plotly.ipynb`: 인터랙티브한 시각화 그래프 구현

### 2. 데이터 전처리 및 실무 실습 (Preprocessing & Practice)
*   **Preprocessing (`preprocessing.ipynb`)**: 결측치 처리, 스케일링, 인코딩 등 머신러닝 모델 입력 전의 데이터 정제 과정
*   **Boston Housing (`Boston.ipynb`)**: 보스턴 주택 가격 데이터를 활용한 회귀 분석 및 실제 데이터 분석 흐름 파악
*   **Kaggle Practice (`Kaggle.ipynb`)**: 기본적인 파이프라인 및 전략 학습

### 3. 기타 리소스
*   `middle.ipynb`, `p70.ipynb`: 세부 주제별 심화 실습 및 문제 풀이
*   `excel-comp-data.xlsx`: 외부 엑셀 데이터를 파이썬 환경으로 불러와 분석하는 실습용 데이터셋

## 사용 기술
*   **Language**: Python 3.x
*   **Environment**: Jupyter Notebook
*   **Libraries**: NumPy, Pandas, Matplotlib, Seaborn, Plotly, Scikit-learn
